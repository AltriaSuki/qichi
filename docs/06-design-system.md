# 06 · 设计系统「晨雾 · 新方向」

> 设计稿：`design/screens/New-*.dc.html`（画布的「新方向」页，规范页是 `New-Spec.dc.html`）。上一版「晨雾」的稿子保留作对照。
> 本文件是把设计稿翻译成代码时的规则；两者冲突时以本文件为准，并提醒人类更新设计稿。
> 2026-09-24 人类选定：字和层次参考 Day One、iA Writer、Bear，颜色沿用晨雾，界面可以花哨一些、多一些装饰。

## 1. 气质

- **晨雾的底色**：四种天色、两个人的颜色、雾白的卡片、极淡的纸纹颗粒都保留。
- **好读的字**：正文用黑体，数字用等宽字，标题靠粗细和荧光笔分层（Day One、Bear）；写作时 Markdown 符号用灰色等宽字（iA Writer）。
- **像一本两个人的手账**：照片是拍立得、贴着胶带；一年前的今天是一张盖了邮戳的邮票；定下来的决定盖一个章；没揭晓的回答封着蜡封；页角长着绿萝。
- **每个功能是一个整体**：每个功能有固定的图标和颜色，在「一起」目录、功能首页、单项页顶栏里一致；进到一个功能，别的功能不打扰。

> 「阿栖是玫瑰色、小迟是雾蓝」只是设计稿里的示例。实际规则：**房间的创建者用 personA，另一位用 personB**，与名字无关。

对应的 Kotlin 结构（放在 `core/designsystem/Sky.kt`）：

```kotlin
enum class Sky { Dawn, Day, Dusk, Night }

@Immutable
data class QichiColors(
    val background: Color, val surface: Color, val paper: Color,
    val ink: Color, val muted: Color, val faint: Color,
    val line: Color, val line2: Color, val accent: Color,
    val personA: Color, val personB: Color, val onPerson: Color, val card: Color,
    val isDark: Boolean,
)

val DayColors = QichiColors(
    background = Color(0xFFECEBE6), surface = Color.White.copy(alpha = 0.60f), paper = Color(0xFFF7F6F2),
    ink = Color(0xFF2A2F35), muted = Color(0xFF5D6167), faint = Color(0xFF9DA0A3),
    line = Color(0xFFDAD9D3), line2 = Color(0xFFC4C4BE), accent = Color(0xFF9A5552),
    personA = Color(0xFFA8625F), personB = Color(0xFF4F6B7A), onPerson = Color.White,
    card = Color(0xFFFBFAF7), isDark = false,
)
// DawnColors、DuskColors、NightColors 按上表同样写出

fun skyAt(localTime: LocalTime): Sky = when {
    localTime < LocalTime.of(5, 0) -> Sky.Night
    localTime < LocalTime.of(8, 0) -> Sky.Dawn
    localTime < LocalTime.of(17, 0) -> Sky.Day
    localTime < LocalTime.of(19, 30) -> Sky.Dusk
    else -> Sky.Night
}
```

通过 `CompositionLocal` 提供 `LocalQichiColors`，每分钟检查一次是否需要切换。Material 3 的 `ColorScheme` 由 `QichiColors` 映射生成，只为了让内置组件不出错。深夜时状态栏图标用浅色。

淡色一律是上表颜色加透明度，不另取新色：卡片底 `α .10–.12`、功能色块底 `.15`、荧光笔 `.22–.24`、胶带 `.30`、标签底 `.12`、署名衬底 `.16`。深夜时同样的透明度套在深夜的颜色上。

## 4. 间距、圆角、阴影、尺寸

- 间距只用这些值：4、8、12、14、16、18、22、28、40（dp）。页边距 28（卡片列表 24）；今天页区块之间 40；详情页区块之间 18–22。
- 圆角：浮起的卡片、便签、日历格子 14；纸张（书页、文稿、信封、档案卡）6；按钮、输入框、分段切换全圆；功能色块 = 边长 × 0.3；人物标记圆形。
- 浮起阴影 `lift`：白天 `0 1 0 line, 0 12 28 rgba(43,50,58,.08)`；深夜 `0 1 0 rgba(0,0,0,.3), 0 12 28 rgba(0,0,0,.3)`。新建按钮单独用更重的一档。
- 分隔线用 1dp **虚线**（line2），不用实线。
- 触控区域最小 44dp；列表行 50–60dp。

## 5. 三层页面

所有页面只有三种顶栏，行的位置一样（状态栏下 40dp 起，一行 44dp）：

| 层 | 页面 | 顶栏 | 底部 |
|---|---|---|---|
| 主页 | 今天、聊天、一起、我的 | 右边两人标记或图标；下面大标题（荧光笔）+ 一句手写；右侧角落一枝绿萝。今天页换成插画和日期大字；聊天是收起形态（对方名字 + 一句手写心情） | 底部四个标签 |
| 功能首页 | 心情、问答、日历、待办、计划、灵感、写作、留言、时间线、档案、决定、阅读、审稿、总结 | 返回（永远回「一起」）+ 右边最多两个图标（其余进「更多」）；下面「功能色块 + 大标题 + 一句手写」 | 新建：右下角深色胶囊 |
| 单项 | 一个计划、一篇文稿、一本书、一份审稿、一个决定、一份总结 | 返回（回功能首页）+ 两行：功能色小字功能名 / 这一项的名字 + 右边图标 | 保存、提交放底栏右侧；字数、进度放底栏左侧 |

- 分组切换一律用顶栏下的**分段切换**（浅底胶囊，选中那格是 `card` 色浮起）。
- 主按钮只放三处：新建 → 右下角浮动胶囊；提交一张表 → 表单最后；保存正在编辑的 → 底栏右侧。
- 进了功能就不显示底部标签。

**正文优先的两页（P12，2026-09-26 人类选定；设计稿 New-Reading、New-Writing 以此为准）**

- **书页（沉浸阅读）**：纸色铺满整屏，没有边框和阴影。打开时顶栏、进度、状态栏都收起，点页面中间叫出或收起，点左右边缘翻页。收起时底部只留一行 11sp `faint` 的页码；叫出时是单项顶栏 + 两人进度条（都用 `background` 底，和正文之间一条虚线）。书签带只在这一页有书签时出现，贴在右上角，不占正文位置。书还没打开、出错或开着读屏时，工具栏一直显示。
- **文稿编辑器**：横线纸铺到屏幕两边，没有留边和阴影；页边线离左边 28dp。键盘打开或手指往下滑时，顶栏收成一行窄条（返回 + 标题），往上滑回来、收起键盘时再展开（停下不自动展开，免得正文上下跳）。底栏浮在纸面上：左边一行「字数 · 分钟 · 保存状态」，右边字号和「存为 vN」，背后纸色渐隐；正文底部留出它的高度。「谁写了多少字」只在打开署名时显示。书签带只给置顶文稿，放在右上角，不占位。键盘弹出时底栏让给格式按钮，保存按钮在格式按钮那一排的最右边。

## 7. 装饰

只从这一套里取，每屏最多三种；装饰贴在内容边上，不压住要读的字；「减少动画」时装饰本来就不动。

| 装饰 | 画法 | 用在哪 |
|---|---|---|
| `Tape` 胶带 | 半透明功能色长条，带细竖纹，两端锯齿，倾斜 ±3–8° | 拍立得、便签、问答卡、计划封面 |
| `Polaroid` 拍立得 | `card` 色相框、下边留白写手写说明、倾斜 ±3° | 聊天里的照片、时间线照片 |
| `Stamp` + `Postmark` 邮票和邮戳 | 相框四边一圈半圆齿孔；圆形邮戳（「栖迟」+ 日期）+ 三道波浪 | 一年前的今天、留言信封 |
| `Seal` 印章 | 暮玫瑰方章，宋体竖排「栖迟」/「定」，内圈白线 | 今天页日期旁、我的头像、决定、总结封面 |
| `WaxSeal` 蜡封 | 不规则圆，内圈线，中间宋体一个字 | 没揭晓的回答、置顶留言、年度回顾 |
| `Sprig` 绿萝线描 | 一根弯茎、七片心形叶，雾蓝线、淡填充 | 主页右上角、聊天背景角落、空页、加载中 |
| `Marker` 荧光笔 | 字下半截衬一道淡色 | 大标题、总结的标题句 |
| `HandNote` 手写 | Long Cang | 问候、功能名旁一句、批注、签名 |
| `Sticker` 贴纸 | 虚线圆角框 + 手写字，倾斜 | 「需要安慰」「第 41 题」「还在想」「新」 |
| `Ribbon` 书签带 | 暮玫瑰竖条，底部燕尾 | 置顶文稿、书页、编辑器纸张 |

## 9. 动效

- 只在四处用动效：天色切换（800ms 淡入）、页面进出（200ms 淡入 + 8dp 位移）、问答揭晓（蜡封淡出、两份答案同时淡入）、AI 正在写（三个点依次变淡）。
- 装饰不动；不用弹跳、不用夸张缩放。
- 「减少动画」开启时全部改为直接切换。
